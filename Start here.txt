AI-FluxMux 0.2.2 beta
=====================

WHAT YOU NEED BEFORE RUNNING
----------------------------
1. .NET 10 Desktop Runtime (Windows).
   - AI-FluxMux is a .NET 10 app. If it is not already installed, download the
     "ASP.NET Core Runtime 10.0" or ".NET Desktop Runtime 10.0" installer from:
     https://dotnet.microsoft.com/download/dotnet/10.0
   - Pick the 64-bit (x64) installer. After installing, start AI-FluxMux again.
   - If the app opens, you already have it — skip this.

2. For the optional in-app updates, these extra tools are needed (only if you use
   that specific update — AI-FluxMux itself does not need them):
   - DeepSeek Harness update  -> Node.js (provides npm).  https://nodejs.org/
   - llama-server update      -> nothing extra (uses the built-in .NET + internet).
   - AI-FluxMux update        -> nothing extra (uses the built-in .NET + internet).
   - If a prerequisite is missing, the "Update now" button tells you and links to the
     installer — it will not close the app.

WHERE THE LAUNCH FILE IS (and why it differs)
---------------------------------------------
- Release zip (normal install): after you unzip AI-FluxMux-0.2.2-beta, the launch
  file is in the ROOT of that folder:
      <folder>\FluxMux.Avalonia.exe
  This is the normal case. Double-click it.

- Source / dev tree (a folder that contains FluxMux.Avalonia.csproj): there is NO
  launch exe in the root. The built exe lives in:
      <folder>\bin\Debug\net10.0\FluxMux.Avalonia.exe
  Two ways to run from a source tree:
    a. Double-click "start-ai-fluxmux.cmd" in the project root — it builds (Debug)
       and starts the exe for you. This is the easiest.
    b. Or build first (dotnet build), then run bin\Debug\net10.0\FluxMux.Avalonia.exe.
  The exe is not in the root of a source tree because the root is the *source*
  (code + project files); the build output goes to bin\Debug\net10.0. The release
  zip is different: it is the *built* output, so the exe sits in its root.

HOW TO START (release zip)
--------------------------
1. This file is inside the unzipped AI-FluxMux-0.2.2-beta folder. Keep that folder
   somewhere you own (for example C:\AI-FluxMux). Do not use Program Files — Help
   updates write next to the program.
2. In that same folder, double-click FluxMux.Avalonia.exe. Windows SmartScreen may
   ask you to choose More info, then Run anyway (this build is not code-signed).
3. Open the Help tab in AI-FluxMux. Start with Install AI-FluxMux, then llama-server,
   then your local model folder and Client app (Cline or DeepSeek Harness).
4. Point the Client app at Port http://127.0.0.1:5001, model id local. Do not point
   it at llama-server.
5. Settings are stored in %AppData%\AI-FluxMux\ — not in this folder.

HOW TO START (source / dev tree)
--------------------------------
1. Make sure the .NET 10 SDK is installed (dotnet on PATH):
   https://dotnet.microsoft.com/download/dotnet/10.0
2. In the project root (the folder with FluxMux.Avalonia.csproj), double-click
   "start-ai-fluxmux.cmd". It stops any running instance, builds Debug, and starts
   the exe with the project folder as the working directory (so the Help.html next
   to the csproj is used, not a stale copy in bin\Debug).
3. Or build by hand:  dotnet build FluxMux.Avalonia.csproj -c Debug
   then run bin\Debug\net10.0\FluxMux.Avalonia.exe.

If you are reading this from a source-code download (a folder named AI-FluxMux-main)
instead of the release zip, there is no ready-to-run exe in the root: that download
is the source to build from. Either use the release zip (exe in the root) or follow
the "source / dev tree" steps above. See the README "Install (Release zip)" step 1
for the direct download link.

This is a beta. llama-server, local model files, and the Client app are separate
downloads. Help names them in plain language.
