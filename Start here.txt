AI-FluxMux 0.3.3 beta
=====================

QUICK START (Release zip)
-------------------------
1. This file is inside the unzipped AI-FluxMux-0.3.3-beta folder.
   Keep that folder somewhere you own (for example C:\AI-FluxMux).
   Do not use Program Files — AI-FluxMux needs to be able to write to the same folder (Windows prevents writes to Program Files by default).

2. In that same folder, double-click FluxMux.Avalonia.exe to launch.
   Windows SmartScreen may ask you to choose "More info", then "Run anyway"
   (this build is not code-signed).

3. Open the Help tab in AI-FluxMux. Start with:
   - Install AI-FluxMux
   - Install llama-server
   - Set your local model folder
   - Configure your Client app (Cline or DeepSeek Harness)

4. Point the Client app at:
   - Port: http://127.0.0.1:5001
   - Model ID: local
   - API key: (blank)
   Do NOT point it at llama-server.

5. Settings are stored in %AppData%\AI-FluxMux\ — not in the unzipped folder.

NOTES
-----
- This release zip is self-contained — it bundles the .NET 10 runtime,
  so no .NET install is needed.
- llama-server and local model files (.gguf) are separate downloads.
  The Help tab links to the correct versions.
- This is a beta. If something goes wrong, check the Help tab or
  the GitHub issues page.

FOR DEVELOPERS (Source / dev tree)
----------------------------------
If you are reading this from a source-code download (a folder named
AI-FluxMux-main) instead of the release zip, there is no ready-to-run
exe in the root. That download is purely the source to build from.

To build and run from source:
1. Make sure the .NET 10 SDK is installed (dotnet on PATH):
   https://dotnet.microsoft.com/download/dotnet/10.0

2. In the project root (the folder with FluxMux.Avalonia.csproj),
   build and run:
   dotnet build FluxMux.Avalonia.csproj -c Debug
   dotnet run --project FluxMux.Avalonia.csproj -c Debug

Or use the release zip (exe in the root) instead.
